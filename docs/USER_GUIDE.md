# Bhandar — User Guide

## Install
- Firefox/Zen: load unpacked via about:debugging, or install the .zip from releases.
- Chrome: load unpacked via chrome://extensions (Developer mode).

## Usage
1. Open the sidebar (View → Sidebar → Bhandar).
2. Drag extension cards between sections to reorganize.
3. Click theme toggle for dark/light.
4. Optional: enable the download modal in settings.

## Permissions
- downloads, storage (required). notifications (optional, toggle in popup).
