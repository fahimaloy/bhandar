# Usage Guide — Bhandar

## Dashboard
Open the sidebar (View → Sidebar → Bhandar). You'll see sections: Images, Videos, Music, GIF, Documents.

![Dashboard](screenshots/dashboard.png)

## Drag and Drop
Drag any extension card (e.g. `.gif`) from one section to another. Changes are saved automatically.

![Drag and drop](screenshots/dragdrop.png)

## Theme
Click the 🌙/☀️ toggle in the top bar to switch dark/light.

![Theme toggle](screenshots/theme.png)

## Permissions (Android / optional)
Open the popup and toggle optional permissions (notifications).

![Popup](screenshots/popup.png)
