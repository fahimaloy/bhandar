# Bhandar

> A premium, lightweight browser extension that sorts downloads into folders by file type.

![logo](src/assets/logo.svg)

## Features
- Default presets: Images, Videos, Music, GIF, Documents (non-deletable).
- Drag-and-drop extension cards between sections.
- Collapsible sections with animated UI.
- Dark/light themes with glassmorphism.
- Auto or modal download mode.
- Cross-browser: Firefox, Zen, Chrome, Android Firefox.
- Permission toggle UI for optional permissions.

## Install
- Firefox/Zen: load unpacked via `about:debugging`, or install the `.zip`.
- Chrome: load unpacked via `chrome://extensions`.
